# SRS Vision rebrand

The visible website branding has been changed from 3FS to **SRS Vision**, including the
dashboard, login screen, team portal, headings, reports, audit labels, and exported report
labels. The supplied blue/cyan/purple SRS Vision logo is used throughout the new dashboard and portal.

Important: internal JavaScript event names, localStorage keys, Supabase table/function names,
and database identifiers that contain `3fs` were intentionally left unchanged so the existing
Supabase data and realtime sync continue to work without a database migration.



The SRS Vision dashboard is now credential-free and does not contain hard-coded admin usernames or passwords.

The existing contact email, phone, address and website values were not invented or replaced.
Update those fields with SRS Vision's real business details before publishing.


## Dashboard design
The dashboard UI has been redesigned from the supplied SRS Vision concept using a dark navy glassmorphism layout, blue/cyan/purple gradients, project panels, team cards, recent activity, calendar, quick stats, and a cinematic hero banner. The supplied concept image is included as `srs-vision-dashboard-concept.png`, and its hero artwork is used as `srs-vision-dashboard-hero.jpg`.
