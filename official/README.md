# SRS Vision Official Website starter

Initial responsive animated homepage prototype in `official/`.

## Original logo
Put the user's own logo image at `official/assets/logo.png`. No substitute logo is included. The page currently references that path.

## Preview
Open `official/index.html` in a browser. This is an initial front-end prototype; Firebase, quote calculator, enquiry persistence, publishing controls, and internal dashboard integration are not connected yet.

## Upload
Preserve the existing repository files and upload this `official` folder to the repository root. Intended public URL is `/official/` after GitHub Pages configuration.
